# OGP画像メーカー(ogp-generator)

ブログや SNS 用の OGP 画像・サムネイルを、テンプレートからブラウザだけで作るツール。画像生成は Canvas でブラウザ内完結し、サーバーにはアップロードしない。

## 概要

- タイトル・サブテキスト・著者名を入れて、テンプレートを選ぶだけで 1200×630 などの OGP 画像を作成
- 背景は単色 / グラデーション / 画像(暗さ調整つき)から選べる
- PNG でダウンロード。有料プラン(モック)では 2x の高解像度で書き出し、PRO テンプレの透かしが消える

## 想定ユーザー

- 個人ブログ(WordPress・はてな・Zenn・Qiita など)の書き手で、記事ごとのアイキャッチを毎回 Canva で作るのが面倒な人
- note・X・YouTube に投稿する個人クリエイターで、テキスト中心のサムネを素早く作りたい人
- デザインツールに不慣れな小規模事業者・個人開発者(サービスの告知画像など)

## MVP の機能

- [x] テキスト編集(タイトルは改行可、日本語の折り返しと簡易禁則、収まるまで自動で文字サイズ縮小、溢れたら末尾を省略)
- [x] テンプレート選択(無料 3 種 + PRO 2 種、現在の文言でサムネ表示)
- [x] 背景・色の編集(単色 / グラデーション / 画像、文字色、アクセント色、コントラスト不足の警告と自動補正)
- [x] フォント(ゴシック / 明朝 / 丸ゴシック ※OS のフォントを使用)と左揃え / 中央揃え
- [x] サイズプリセット(OGP 1200×630、X 1200×675、YouTube 1280×720、note 1280×670、正方形 1080×1080)
- [x] PNG 出力(無料 1x / 有料モック 2x)
- [x] 入力内容を localStorage に保存(背景画像は容量のため保存しない)
- [ ] Web フォント同梱(端末差をなくす)
- [ ] ロゴ・アイコン画像の配置
- [ ] 課金・ログイン

## 構成

- Vite 6 + React 18 + TypeScript の静的サイト(Cloudflare Pages に `dist/` を置く想定)
- `src/lib/wrap.ts` … 折り返し・文字サイズ調整(Canvas 非依存でテスト可能)
- `src/lib/templates.ts` … テンプレート定義。`Template` を 1 つ足せばテンプレが増える
- `src/lib/render.ts` … 背景 → テンプレ → 透かしの順に Canvas へ描画、PNG 化
- `src/lib/storage.ts` … 保存先(`DesignStore` インターフェースで Supabase 等へ差し替え可能)
- `src/lib/color.ts` … コントラスト比の計算

## 開発

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 型チェック + 本番ビルド
npm test         # node --test(折り返し・色・書き出しのテスト)
```

## 収益化案

- 無料: 1x(OGP 標準サイズ)で書き出し、基本テンプレ 3 種
- 有料(買い切り or 月額 300〜500 円程度): 2x 高解像度、PRO テンプレ、Web フォント追加、ロゴ配置、ブランド設定(色・フォント)の保存
- 将来案: URL を渡すと記事タイトルを読んで OGP を自動生成する API(ブログ運営者・開発者向け、Cloudflare Workers + Satori 系)
- 補助的に、無料ページへの控えめな広告枠

## 集客案

- 「OGP 画像 作成」「アイキャッチ 作り方」「YouTube サムネ 文字だけ」などの検索向けに、用途別のランディングページ(サイズ別・媒体別)を用意
- 作成画像の右下に任意の小さなクレジット(オフにできる)を入れ、SNS 上で自然に広がるようにする
- Zenn / Qiita / note で「OGP 画像を自動で作る仕組み」の技術記事を書き、開発者層に届ける
- WordPress / Hugo / Astro 向けの使い方ガイドを公開し、ブログ運営者のブックマークを狙う
- 同じブラウザ内完結ツール(image-compress など)から相互リンク

## 次にやること

1. Web フォント(Noto Sans JP 等、ライセンス確認済みのもの)を同梱し、読み込み完了後に描画する
2. ロゴ / アイコン画像の配置、絵文字・強調文字(一部だけ色を変える)
3. テンプレ追加(技術ブログ向け、YouTube 向けの太字縁取り、写真 + 帯)
4. ブランド設定のプリセット保存と、JSON エクスポート / インポート
5. 課金(Stripe 等)とログイン(Supabase Auth)で有料判定を本実装
6. Cloudflare Pages デプロイ設定、OGP・サイトマップ・用途別ランディングページ
